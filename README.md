# Codi — Software Testing Portfolio

A portfolio of my testing contributions to **Codi**, a team project for an online learning platform. This repository contains project testing documents and test cases.

> **Scope:** This is a software testing portfolio, not the original Codi application source code. No application source code is included.

## My contributions

- Designed unit tests for `addCourseToCart` using Vitest, as assigned in the team test plan.
- Designed and executed the assigned cart system test cases `TC_CART_001`–`TC_CART_004`.
- All four assigned cart cases are recorded as **Pass** in the supplied system test workbook.
- Contributed within a team testing effort covering the cart and vouchers, checkout and payment, and personalized learning paths.

## Team test results

The supplied system test workbook reports **27/27 system test cases passed** across the team's three feature areas. This is the overall team result; it should not be read as an individual result.

The Vitest research report documents five CART cases for `addCourseToCart` and five SEARCH cases for `filterCourseCatalog`. Its coverage figures describe the documented project test run, not coverage attributable to one contributor.

## Tools and methods

- **Unit testing:** Vitest 5, TypeScript
- **System testing:** Playwright
- **Test design:** Equivalence partitioning, boundary value analysis, statement coverage, and decision coverage
